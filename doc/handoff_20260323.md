# 프로젝트 인수인계 문서 (Handoff for Claude)

## 1. 프로젝트 개요 (Project Overview)
- **프로젝트 명:** 순천순동교회 홈페이지 (Next.js 14 App Router, Supabase, Tailwind CSS)
- **주요 기능:** 기존 교회 소개, 예배 안내, 공지사항 기능 외에 **유튜브 영상 주소를 입력하면 AI가 자동으로 설교를 3줄 요약하고 홈페이지 메인에 게시하는 시스템** 구축.

## 2. 금일 진행 내역 상세 (시간/흐름순)

### Phase 1: 기본 홈페이지 정보 업데이트
- 하단 푸터(`Footer.tsx`) 및 메인페이지(`page.tsx`)의 연락처, 담임목사, 주소, 비전, 예배시간표 하드코딩 데이터를 주보에 맞게 최신화 완료.

### Phase 2 ~ 3: 자동 설교 요약 시스템 아키텍처 및 구현
- **기획안 작성:** `sermon_automation.md`, `api_setup_guide.md`, `implementation_plan_sermon.md` 등의 문서를 `brain` 폴더 또는 로컬에 작성 완료.
- **데이터베이스 (Supabase):**
  - `schema.sql`에 `sermons` 테이블 생성 (youtube_id, title, summary, status: 'draft'/'published').
- **백엔드 리소스 (`api/sermons/parse/route.ts`):** 
  - `youtube-transcript` 라이브러리로 유튜브 자막 추출.
  - `@google/generative-ai` 모듈로 Gemini API 연동.
  - 🚨 **[중요 트러블슈팅]** 2026년 기준 구글에서 `gemini-1.5-flash` 모델 접속을 완전히 차단(404 Not Found 에러)한 범용적 이슈가 발생하여, 백엔드 API 호출 모델명을 가장 최신인 **`gemini-2.5-flash`** 로 긴급 상향 패치 및 정상 작동 대기 중.
- **관리자 대시보드 UI (`admin/sermons/page.tsx`):**
  - 유튜브 링크를 붙여넣고 [AI 설교 요약 시작] 버튼 탭 시, Draft(검토 대기중) 상태로 DB에 인서트되고 관리자가 승인(Published)하는 화면 구축.
- **홈페이지 연동 (`app/page.tsx`):**
  - "이번 주 하나님의 말씀" 섹션을 신설하여 DB에서 `status === 'published'`인 최신 설교 목록 노출 처리 완료.
- **관리자 UI 및 네비게이션 디버깅:**
  - 상단 `Navbar.tsx` 우측에 admin 계정 접속 시 나타나는 `/admin` 버튼("관리자 홈") 추가.
  - 관리자 레이아웃(`admin/layout.tsx`)의 좌측 사이드바(Sidebar)에 *[설교 요약 관리]* 탭 연결 및 추가.
  - 여백(`pt-16`)이 이중 점용되어 화면 상단이 비어보이던 레이아웃 갭 이슈 수정(`layout.tsx`).

### Supabase Auth / React 클라이언트 이슈 (최신 디버깅 사항)
1. **Email Rate Limit 이슈:** 이메일 인증 기능 해제를 유도했으나 최신 Supabase 무료 티어에서는 이메일 SMTP 연동 없이 인증을 끄지 못함. 유저가 회원가입 연타로 Rate Limit에 걸려, 우회 수단으로 대시보드(Authentication > Users)에서 **관리자 계정(`admin@church.com`)을 수동 생성**하고 본문 `profiles` 테이블에 **role 값을 `admin`**으로 강제 `Insert` 하여 관리자 로그인을 성공시킴.
2. **Infinite Loader 빙빙 도는 버그:** `/admin` 페이지 접속 시 `checkAdmin` 권한 확인 로직의 `useEffect` 의존성 배열(dependency array)에 `supabase = createClient()` 클라이언트 객체가 들어가 있어 무한 리렌더링 및 프로미스 행(hang) 현상 발생. 
   - 조치: 의존성 배열에서 `supabase` 제거, `try-catch` 삽입, 네트워크 체증에 대비하여 **강제로 5초 뒤에 `setLoading(false)` 락(lock)을 푸는 failsafe 타임아웃 방어 코드**를 작성 완료.

## 3. 현시점 보류 상태 (Current Status)
- `admin` 권한 확인 후 로딩 스크린이 종료되지 않는 현상을 방금 수정했으나, 로컬 브라우저 상에 잔존하는 기존 Next.js 핫 리로드 메모리 찌꺼기 문제로 **f5 (새로고침) 및 5초 대기**를 통해 강제 로딩 해제를 클라이언트(USER)가 테스트 중입니다.

## 4. Claude Code 이관 시 주의사항 & Next Steps (클로드 전용 메모)
- **Role 정책 관련:** 이 프로젝트의 시스템 권한 검사는 User Metadata 내부에 값이 있는 것이 아니라, 회원가입 시 트리거가 돌며 생성되는 `public.profiles` 테이블의 **`role` 컬럼** 값이 기준입니다. (`select('role')`으로 권한 검사 수행 중)
- **환경 변수(.env.local):** `GEMINI_API_KEY`, `YOUTUBE_API_KEY`, Supabase URL 및 anon 키핑 정상 셋업되어 작동됨을 전제로 합니다.
- **추가 구현 건의:** AI가 뽑아낸 요약을 실제로 관리자가 `Draft` -> `Publish` 승인 후 홈페이지 대문에서 잘 보이는지 E2E 테스트 확인하고, 필요 시 UI 폴리싱 및 추가 게시판(주보 등) 작업을 이어가면 됩니다.
